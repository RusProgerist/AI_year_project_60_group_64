# Описание проекта

Идея данного проекта состоит в создании цифрового помощника, к которому обращаются клиенты (люди с ментальными проблемами) перед получением квалифицированной помощи от профессионала. Помощник в виде чат - бота на сайте или внутри приложения выясняет, какие беспокойства есть у человека, оценивает срочность проблемы, пишет основу клинической картины и передает данные нужному специалисту. Врач получает готовую картину до первой встречи и может сосредоточиться на живом общении, а не на сборе информации от клиента.
